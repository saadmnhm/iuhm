🚀 QUICK START (3 STEPS)

Step 1: Access Admin Panel
──────────────────────────
  Navigate to: /admin/media

Step 2: Upload Media Files
─────────────────────────
  • Click "📁 Upload Media"
  • Add title, description, category
  • Upload file (max 50MB)
  • Make public for API access
  • Save

Step 3: Use via API
──────────────────
  • GET /api/v1/media                    (list all)
  • GET /api/v1/media/latest?limit=5     (latest files)
  • GET /api/v1/media/category/{name}    (by category)
  • GET /api/v1/media/search?q={query}   (search)
  • GET /api/v1/media/{id}               (get specific file)

📡 API ENDPOINTS

All endpoints return JSON with {status, data, pagination}

GET  /api/v1/media                      ← List all media
GET  /api/v1/media/{id}                 ← Get specific file
GET  /api/v1/media/latest               ← Get latest files
GET  /api/v1/media/most-used            ← Most used files
GET  /api/v1/media/search               ← Search media
GET  /api/v1/media/category/{category}  ← By category
GET  /api/v1/media/type/{type}          ← By MIME type
GET  /api/v1/media/categories           ← List categories
GET  /api/v1/media/stats                ← Get statistics
GET  /api/v1/media/download/{id}        ← Download file

💻 INTEGRATION EXAMPLES

JavaScript
──────────
fetch('https://domain/api/v1/media/category/logos')
  .then(res => res.json())
  .then(data => console.log(data.data))

React
─────
const [media, setMedia] = useState([]);
useEffect(() => {
  fetch('https://domain/api/v1/media/latest?limit=5')
    .then(r => r.json())
    .then(d => setMedia(d.data));
}, []);

Vue.js
──────
mounted() {
  fetch('https://domain/api/v1/media')
    .then(res => res.json())
    .then(data => {
      this.media = data.data;
    });
}

PHP
───
$media = Http::get('https://domain/api/v1/media')
  ->json()['data'];

Python
──────
import requests
response = requests.get('https://domain/api/v1/media')
media = response.json()['data']

📂 DATABASE TABLE

Table: media
├─ id (bigint)
├─ title (string) - English
├─ title_ar (string) - Arabic
├─ description (text) - English
├─ description_ar (text) - Arabic
├─ file_name (string)
├─ file_path (string) - Storage path
├─ file_size (integer) - Bytes
├─ file_type (string) - Extension
├─ mime_type (string) - MIME type
├─ category (string) - Indexed for filtering
├─ tags (json) - Array of tags
├─ is_public (boolean) - Visibility toggle
├─ uploaded_by (bigint) - User ID
├─ usage_count (integer) - API access counter
├─ created_at (timestamp)
├─ updated_at (timestamp)
└─ deleted_at (timestamp) - Soft deletes

📋 PERMISSIONS & ACCESS

Module Permission: module:media

Add to admin roles in:
  Admin Console → Roles → Select Role → Add "media" module

Only admins with this permission can:
  • Access /admin/media
  • Upload files
  • Edit metadata
  • Delete files
  • Toggle visibility

---

API Access:
  • Public (no auth required)
  • Only PUBLIC media accessible
  • All endpoints return JSON
  • No rate limiting (can be added)

🔧 FILE STORAGE

Location: uploads/media/{YEAR}/{MONTH}/{filename}

Example path:
  uploads/media/2026/05/507895d6ea69d_1714857600.png

Directory structure:
  uploads/
  └── media/
      ├── 2026/
      │   ├── 05/
      │   │   ├── file1.png
      │   │   ├── file2.pdf
      │   │   └── file3.jpg
      │   ├── 06/
      │   └── ...

Files are automatically deleted from storage when media record is deleted.
